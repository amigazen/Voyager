7.2 Obtaining Support

For Voyager 3.5.2 use GitHub or email. The VaporWare bug tracker, FTP site, and mailing lists are long since offline.

7.21 Web and GitHub 

https://github.com/amigazen/Voyager
http://www.amigazen.com/voyager/
https://zapek.com/software/voyager/  (historical notes)


7.22 Historical VaporWare sites

http://www.vapor.com/, ftp://ftp.vapor.com/, and v3.vapor.com were the original product sites. They are offline (and www.vapor.com is no longer VaporWare). Do not use them for updates or keyfiles.


7.23 Email

voyager@amigazen.com

The old list voyager@vapor.com / voyager-request@vapor.com is not operated for 3.5.2. JSERROR.LOG in the program drawer is still useful when the Javascript error-log preference is on.


7.24 Installation notes

Copy the Workbench drawer as shipped. MUI and a TCP/IP stack are your responsibility. AmiTLS is required for HTTPS. See install.html.
