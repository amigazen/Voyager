Voyager V3 3.5. Historical FAQ by Benjamin C. Steeves (1997-1998), annotated for 3.5.

8.2 Voyager and the web

Questions 3.x and 5.x of the 1998 FAQ. SSL is in 8.3.


Frames, JavaScript, Java

1998: Frames yes (FRAMESET, NOFRAMES, FRAME SRC, TARGET). SCROLLING=NO was ignored (you could still scroll). JavaScript was not supported in 2.95; from 2.88 the browser ignored script. jslib.library was an old stub. Java was "not yet"; Wagner and Haage & Partner were said to be working on a JVM for 1998. Java vs JavaScript: Java is compiled bytecode for a VM (applets); JavaScript is source mixed into HTML [after Mike Weaver].

3.5: Frames remain. JavaScript is supported: a JS 1.3 / ECMA-Script bytecode compiler and interpreter, with a Javascript settings page and optional JSERROR.LOG. It is not a modern engine; many current sites will fail. There is no Java (no applets, no Haage & Partner JVM). <SCRIPT> / <NOSCRIPT> are layout tags; CSS is not applied.


Anonymous browsing and spoofing

1998: Security settings could omit the Referer: header. That is not real anonymity; an anonymizing proxy (the FAQ named www.anonymizer.com) was stronger. Proxies were set in Net settings. From 2.91, Settings could "Spoof as Mozilla". Older builds were hex-edited: both User-Agent strings in the executable. Spoofing does not turn Voyager into Netscape; a site that demands Netscape may use tags Voyager cannot render.

3.5: Don't send Referer: is still in Security prefs. Factory User-Agent uses Firefox 4 grammar with AmigaVoyager in the comment so CDNs are less likely to return 403. Settings / Spoof as Mozilla still exists; it does not add missing HTML/JS. Do not hex-edit V. A privacy proxy still belongs in Network settings if you use one. "Anonymous" HTTP is not a substitute for HTTPS.


HTML tags and VRML

1998: Wagner had a day job; tag requests went to the mailing list without a promised date. Voyager supported most of HTML 3.2. VRML was a 3D web format; an IBrowse plugin was rumoured, with no Voyager promise [Ewald Borger].

3.5: Still an HTML 3.2 layout engine with some later tags. HTML5/CSS3 is out of scope. No VRML. Feature requests: GitHub.


HTTP/1.1

1998: HTTP/1.1 allows persistent connections (many objects on one TCP session) instead of a new connection per image. VoyagerNG 2.92+ (including 2.95) spoke 1.1; 2.88 fell back to 1.0. The "1.1" mark in the lower-left of the window meant the server agreed.

3.5: HTTP/1.1 is still in the network code. The status area still shows protocol information (see The Main Interface). Modern sites may also require TLS 1.2 (faqssl.html) before HTTP even starts.


Documentation, lists, websites

1998: HTML docs from ftp://ftp.vapor.com/pub/voyager/ (vng_docs_v4). Mailing list: mail voyager-request@vapor.com with ADD in the body; save the welcome message. No dedicated newsgroup. Site: http://www.vapor.com/.

3.5: This HTML set is PROGDIR:Docs/voyager3docs/ (Docs fastlink). ftp.vapor.com and the VaporWare list are gone; www.vapor.com is not VaporWare. Use https://github.com/amigazen/Voyager , http://www.amigazen.com/voyager/. Historical notes: https://zapek.com/software/voyager/ . The 1998 FAQ files remain in the GitHub archive/FAQ/ drawer.
