Voyager V3 3.5.2 by Chris Wiles, 1999.

1.4 Installing Voyager 3.5.2

You need MUI 3.8 (or later) before you run Voyager. MUI is on Aminet and many Amiga CDs.

3.5.2 is a Workbench drawer, not the old floppy-era Install_Voyager wizard. Copy the Voyager drawer to a hard disk partition with enough free space, then run V from that drawer.

A TCP/IP stack providing bsdsocket.library must be running. For HTTPS, install AmiTLS so LIBS:amitls.library is available, and keep Certificates/cacert.pem in the Voyager drawer.


1.41 Open the drawer

Open the Voyager drawer on Workbench. Double-click V to start. V.ReadMe and Docs/Readme.Docs describe the same tree.

If an Install_Voyager icon is still present, it is the historical VaporWare script. Prefer copying the 3.5.2 drawer as shipped.


1.42 What used to be Install Mode

The V3 installer asked Intermediate vs Expert and could install AmiTCP. 3.5.2 does not install a TCP/IP stack. Use whatever stack you already run (AmiTCP, Miami, Roadshow, etc.) as long as it offers bsdsocket.library.


1.43 Where to put Voyager

Copy the whole drawer (V, Libs, Plugins, Certificates, Docs, Buttons, Cache). Do not mix it over an old 3.2 or 3.3 install; those subsystems were not compatible even in the VaporWare 3.3.126 readme.

Keep PROGDIR: as the drawer that contains V, so file:///PROGDIR:Docs/... and Plugins/voyager_ssl.vlib resolve.


1.44 MIME Prefs

MimePrefs ships in the 3.5.2 tree. You can leave it next to V, or copy it to SYS:Prefs if you prefer. It is not required by other VaporWare programs unless you still run those.


1.45 Documentation

HTML documentation is already in Docs/voyager3docs/. Open main.html, or use the factory Docs Fastlink (new prefs / factory reset). V.ReadMe is the program readme. README.md and CHANGELOG.md are in the source tree on GitHub.


1.46 HTTPS (AmiTLS)

US export restrictions on the old OpenSSL 0.9 VSSL module do not apply to this build. 3.5.2 ships voyager_ssl.vlib built on AmiTLS (TLS 1.2, SNI). Place:

  • Plugins/voyager_ssl.vlib in the Voyager drawer
  • LIBS:amitls.library from AmiTLS
  • Certificates/cacert.pem (CA bundle) in the Voyager drawer
MiamiSSL is not used. The historical OpenSSL 0.9 tree in the sources is not linked.


1.47 Button sets

Toolbar images live in Buttons/. SpeedBar is enabled. Tear-off panels are disabled in 3.5.2 because TearOffPanel.mcc is not Enforcer-clean.


1.48 Readme vs HTML

Use both: V.ReadMe for 3.5.2 runtime notes, this HTML set for the interface manual.


1.49 Plugins and certificates

3.5.2 does not install vapor_toolkit.library. Required pieces in the drawer:

  • Plugins/voyager_ssl.vlib for HTTPS
  • Certificates/cacert.pem
  • MUI classes in Libs/ (SpeedBar and others as shipped)
The image decoder is linked into V; there is no separate vimgdecode.library to pick by CPU.


1.50 Ready to run

Start your TCP/IP stack, then double-click V. Default homepage is about:. Factory Fastlink Docs opens this manual. If Fastlinks still show old VaporWare URLs, reset factory prefs or add the Docs URL: file:///PROGDIR:Docs/voyager3docs/main.html
