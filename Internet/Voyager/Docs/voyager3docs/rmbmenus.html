3.6 Using Voyager's RMB-Menus

As well as the normal Voyager menus you have a selection of menus when you click your right mouse button. These allow you to save images, add URL's to your bookmarks, enlarge frames etc etc.

Other than the 'Tearoff' menus, there are seven main Voyager RMB-menus: ImageLink Operations, Image Operations, Link Operations, Frame Operations, Anim, Backward/Forward and Page Operations.

3.61 ImageLink Operations RMB-Menu

Load image if you have "load images" turned off you can load individual images by using this option. The image will appear within the browser.

View image separately this will view an image (within a web page) separately from the page - ie. on its own.

View with WebVision sends the animation/image to WebVision, if installed.

Save image to file this option will load and image and save it to your hard drive.

Goto link goto an underlined link.

Open link in a new window will goto to a link and then open the link within a new Voyager window.

Download to file this option will download a link to your hard disk.

Copy URL to Clipboard this will copy a URL link to clipboard.

Add URL to Bookmarks this option will add a URL link to your bookmarks for later use.

Info will show information about the current page.

3.62 Image Operations RMB-Menu

Load image if you have "load images" turned off you can load individual images by using this option. The image will appear within the browser.

View image separately this will view an image (within a web page) separately from the page - ie. on its own.

View with WebVision sends the animation/image to WebVision, if installed.

Save to file this option will load and image and save it to your hard drive.

Copy URL to clipboard will copy the selected hyperlink to clipboard, so you can then paste it to another document, via the Amiga clipboard.

3.63 Link Operations RMB-Menu

Goto link this option will goto a URL (underlined) link.

Open link in a new window will goto to a link and then open the link within a new Voyager window.

Download to file this option will download a link to your hard disk.

Copy URL to Clipboard this will copy a URL link to clipboard.

Add URL to Bookmarks this option will add a URL link to your bookmarks for later use.

Info will show information about the link.

3.64 Frame Operations RMB-Menu

View frame full window allows you to "expand" a frame to the full size of the Voyager window.

Save frame to file you can save the frame information to your hard drive.

Show frame source allows you to show the source of the current frame.

Print frame the current frame.

Find in frame document will locate some text within the frame.

Back  - go back one step within a framed site.

Forward  - go forward on step within a framed site.

Reload Frame Contents  - reload the current frame.

Info will show information about the current frame.

3.65 Anim RMB-Menu

Hide - hide the transfer animation.

3.66 Backward/Forward RMB-Menu

The backward and forward RMB menus allow you to quickly move back and forth via previously visited documents or web pages.

3.67 Page Operations RMB-Menu

Save to file will allow you to save the current page to file (ie. to a file on your hard drive or floppy disk drive).

View source will launch the source view window for the current page. You can then edit the source window or view its contents.

Print the current page. Printing was incomplete after 3.3 and may not work in 3.5.2.

Find in page - find a word within the current page.

Back/Forward - move back and forward through visited pages. These options have the same effect as the back and forward buttons.

Reload page - reload the current page. This has the same effect as clicking the 'reload' button in the Voyager button bar.

Page info - show information about the current page.
