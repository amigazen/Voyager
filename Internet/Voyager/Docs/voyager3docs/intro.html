Voyager V3 3.5.2 by Chris Wiles, 1999.

2.1 What is it?

Voyager 3.5.2 is a restoration of VaporWare's Voyager V3 for classic 68k Amiga. It is a MUI web browser with an HTML 3.2 layout engine (some later tags), a JavaScript 1.3 bytecode compiler and interpreter, plugins, and HTTPS through a loadable voyager_ssl.vlib module.

Oliver Wagner started Voyager in 1995. The last boxed commercial release was Voyager 3.2 (16 April 2000). A limited 3.3 line and a short 3.4 CVS series followed. 3.5.2 is that later GPL tree made to compile and run again.

You can bookmark sites you visit often, or add them as Fastlinks on the main window. Factory prefs include a Docs Fastlink that loads this HTML manual from PROGDIR:Docs/voyager3docs/main.html.

This is still a 1990s / early-2000s browser. It will not render modern HTML5/CSS sites. Amiga sites, archives, and simple HTML are the intended target.
