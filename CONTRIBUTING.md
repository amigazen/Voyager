## Copyright notices

Keep every existing copyright notice. Add your own name when you create a modification. Do not remove, replace, or obscure another person's name, or the notice that the work is derived from their code.

The original Voyager notices are:

```

```

Modifications made in this repository are:

```
Copyright (C) 2026, amigazen project (or other contributor name)
```

That line is carried in the source files this project has modified. It sits beside the original notices. It does not replace them.

The GPL already requires this. In particular:

- Verbatim copies must keep intact all notices stating copyright.
- A modified version must carry prominent notices stating that you modified it, and giving a relevant date.
- A modified version must keep intact all notices of the absence of any warranty, and all copyright notices from the Program.

A fork, mirror, archive, or other redistribution that deletes these notices is not complying with the license. The notices have to be restored before that copy is distributed. Publishing the result as if the original authors had not written the code does not make the deletion lawful.

A change submitted here that strips or reassigns another contributor's credit will not be accepted. 

When you change a file in this tree:

- Leave every existing copyright line in place.
- Add your own copyright line for the modifications you make, with the year of the change.
- Do not move an existing notice into a place where a normal reader of the file will not see it.

Vendored SDK headers (MUI, CyberGraphX, SDI, and similar files under `Source/includestuff`) keep the copyright notices of their authors. Do not replace those notices.

## The official release

The GPL grants rights in the source code. It does not grant the identity of the official amigazen project release of Voyager.

A fork may exercise every right the license grants. It must say plainly that the work is a separate modification of the Voyager sources published by the amigazen project, and it must keep the copyright notices above. It must not present that release as the official amigazen project release, or as endorsed by Oliver Wagner, David Gerber, Jon Bright, or Matt Sealey.

Warranty, support, or other obligations may be offered only in the offeror's own name, never in the name of the amigazen project or of any other contributor.
